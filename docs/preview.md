# Windows 预览版

`0.1.0-preview.2` 保留当前界面风格，缩小默认窗口和页面留白。头像仅作页面元素，应用图标仍用默认占位。

窗口默认 960×660，最小 820×560；启动时还会根据屏幕工作区缩小。长页面在内容区域滚动，侧栏、模式切换和底部状态栏保持可见。

## 开始使用

1. 下载 Windows x64 EXE，直接运行，不需要管理员权限。
2. 在“账户”里创建离线角色。
3. 在“下载”里获取版本列表，选择一个原版版本并下载。
4. 安装这个游戏版本需要的 Java。在“设置”中自动检测，或手动选择 `bin/java.exe`。下载完成的实例会显示需要的主版本。
5. 回到“我的游戏”，点击启动游戏。

也可导入包含 `versions` 文件夹的标准原版游戏目录。导入只记录位置，不复制或删除原文件。暂不支持加载器继承配置和旧版虚拟资源格式。

启动器配置和新下载的游戏实例存放在用户数据目录，可在设置页打开。Windows 通常为 `%APPDATA%/LMCL`。EXE 可单文件运行，用户数据仍保存在这里；移走 EXE 不会迁移存档。

## 已接入

- 原版版本目录、下载、官方文件哈希校验、取消下载；未完成的安装不加入实例列表。
- 离线角色、稳定的离线 UUID、Java 检测与手动选择、内存设置。
- 原版游戏目录导入、独立实例启动、运行状态和游戏日志。
- 普通／服务器模式切换、添加／移除接口、手动查询服务器目录。
- 通过系统协议打开已安装的基岩版。

首次实现还没完成真实 Minecraft 图形运行的人工验证。已完成的自动检查只代表规则、界面、IPC 和打包程序能正常工作；发现启动问题时，查看实例目录中的 `lmcl-game.log`。

## 未接入

微软和 LittleSkin 的实际授权、加载器安装、模组搜索、整合包导入、服务器整合包安装和自动更新执行器。这些入口会明确标为未开放，不显示虚假的下载或登录结果。

## 构建验证

Windows 构建先运行自动测试和桌面冒烟测试，再生成单文件 EXE，随后直接运行该 EXE 做第二次冒烟测试。检查包括：界面和头像加载、离线角色保存、模式切换后账户保留、默认无服务器。构建会保存主页／下载页截图、报告和 SHA-256 校验文件。
