# LMCL

一个正在开发的 Minecraft Java 启动器，先做 Windows。

想解决的事很简单：选好 LID 服务器，启动器准备对应的整合包。服务器发布更新后，自动同步需要变动的模组，不用再手动复制文件。

计划支持：

- 微软正版、LittleSkin 和离线登录，优先推荐正版。
- 游戏版本、加载器、模组和整合包下载。
- LID 服务器列表、在线人数、一键安装和整合包更新。
- 工具箱里打开已安装的基岩版。

UI 会单独设计，暂时还没开始。后续考虑 macOS、Linux，Android 先研究可行性。
