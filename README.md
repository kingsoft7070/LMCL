# LMCL

一个正在开发的通用 Minecraft Java 启动器，先做 Windows

日常可以用来管理游戏版本、模组和整合包，玩单人存档也不需要接入任何服务器。

另外提供可选的服务器模式：添加服务器提供的接口后，查看服务器状态、安装对应整合包，并同步后续更新。LID 也通过这套接口接入，不在公开版本中内置。

计划支持：

- 微软正版、LittleSkin 和离线登录，优先推荐正版
- 游戏版本、加载器、模组和整合包下载
- 普通模式独立使用整合包，服务器模式接入服务器列表、在线人数和整合包同步
- 工具箱里打开已安装的基岩版

UI 会单独设计，暂时还没开始。后续考虑 macOS、Linux 甚至会支持 Android 先研究可行性

公开版本不附带 LID 的服务器地址、整合包、素材或访问凭据。其他服务器可以实现同一套[接入接口](docs/server-api.md)，由用户自行添加。普通／服务器模式的切换入口会在 UI 设计时确定，切换模式不会更换账户或删除已有实例。

## 目前进度

仓库里是核心规则的早期原型，还不能当启动器用，也没有安装包。

已写好离线角色 UUID 和整合包更新计划器，可以计算新增、替换、缺失和移除的文件，保留用户修改的配置，遇到冲突时停下来。游戏运行期间会推迟应用更新。模式配置默认使用普通模式，不带服务器；服务器接入协议目前是草案。

实际登录、下载、文件更新和游戏启动还没接上。现在用 JavaScript 验证规则，桌面端技术栈尚未定下来。
